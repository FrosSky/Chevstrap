Chevstrap is a third-party Android launcher for Roblox, specifically designed for Android and based on [Bloxstrap](https://github.com/bloxstraplabs/bloxstrap).

## Features

- A practical Discord Rich Presence feature that lets your friends know which Roblox game you're currently playing. However, it uses a Discord Gateway connection, **Use this at your own risk.**

- Ability to configure device preferences.
- See where your server is currently located (via [ipinfo.io](https://ipinfo.io/) API).
- Game History lets you view games you've previously played and return to the same Roblox server, unless the server has expired, is no longer available, or is a reserved server that cannot be rejoined.

## Installation

1. Download the [latest release of Chevstrap](https://github.com/FrosSky/Chevstrap/releases/latest).
2. Install the APK on your Android device.
3. Once installed, open Chevstrap and begin using it.

## System Requirements
- OS Version: Android 8.0 through 16
- RAM: 3GB minimum
- Graphics API: OpenGL ES 3.0 or later

## Build

## F.A.Q

#### Q: Is this a malware?

A: No, it's not malware. The source code is public, so you can check it yourself to make sure it's not doing anything harmful. Just make sure you download it from an official source.

#### Q: Can I get banned for using Chevstrap?

A: No. As long as you have never used exploits, including modified Roblox clients or process injectors, and only run the native Roblox client available on the [Google Play](https://play.google.com/store/apps/details?id=com.roblox.client), and your Virtual Space doesn’t improperly manipulate the Roblox client’s memory, you should be fine. [learn more here](https://github.com/FrosSky/Chevstrap/wiki/Why-you-can't-get-banned-by-Chevstrap)

#### Q: Does Chevstrap require root access?

A: No. Chevstrap does not require root access and works on non-rooted Android devices. In fact, Roblox itself does not allow rooted or jailbroken devices, so rooting your device is not required or recommended for using Chevstrap. You can read more about this in [Roblox's Anti-cheat Messages.](https://en.help.roblox.com/hc/en-us/articles/24275616578708-Anti-cheat-Messages)
